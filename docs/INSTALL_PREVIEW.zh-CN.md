# Wattson 预览版安装说明

适用：Apple Silicon Mac（M 系列）。当前包是 arm64，不能给 Intel Mac 使用。编译最低版本是 macOS 13，但目前实际测试只覆盖一台 macOS 26 / M5。

1. 从维护者提供的位置取得 `Wattson-0.1.2-arm64-preview.zip`，解压。
2. 把 `Wattson.app` 拖进「应用程序」。已有旧版时先从 Wattson 菜单退出，再替换应用。
3. 尝试打开；若系统提示无法验证开发者，打开「系统设置 → 隐私与安全 → 仍要打开」，再确认打开。
4. 初次评估保持「自动处置」关闭，让它先学习正常工作负载。已有用户的设置和历史不会因为替换应用而重置，因此请检查实际开关状态。

没有付费 Developer ID 签名和公证也可以使用。这个预览包使用本地 ad-hoc 签名，下载后仍可能出现 Gatekeeper 提示。受组织管理的 Mac 可能不允许自行添加例外；详见 [Apple 官方打开方式](https://support.apple.com/zh-cn/102445)。

如果提示文件损坏，先重新下载并核对 ZIP 的 SHA-256。维护者随包提供 `.sha256` 文件；在 ZIP 所在目录执行 `shasum -a 256 Wattson-0.1.2-arm64-preview.zip` 并对比即可。不要把“损坏”或“恶意软件”提示一概当成签名问题。

自动处置只会请求后台优先级，并尝试恢复；不会自动结束或重启进程。后台优先级可能影响 I/O 和网络调度。没有建立基线、远程连接生命线和系统保护进程不会被自动处置。界面中的手动“结束”另行确认。

普通监控不需要安装 Swift、Xcode 或 Python。GPU 内存上限调整属于独立的高级功能，可能请求管理员权限；初次试用可保持默认值。

测试时请记录：芯片和 macOS 版本、应用版本、问题发生时间、当时的工作负载、是否开启自动处置、能否复现。日志在 `~/.wattson/`；对外分享前删除私人的模型路径、命令行、进程调用栈和通知地址。

卸载时先关闭设置中的登录启动，再退出并移除 `Wattson.app`。历史位于 `~/.wattson/`，可自行保留。开发者预览尚不承诺无人值守稳定性、节电比例或模型吞吐提升。
