## 本次验证的限制

- CLI 引擎测试和签名完整性检查不等于 GUI 全流程、首次互联网下载的 Gatekeeper 交互、或公证验证。
- 尚未用最终包完成另一台 Mac 安装、其他 macOS 版本、登录启动、升级、睡眠唤醒和多天运行验证。
- 这轮没有测量节电量、交互延迟改善或模型吞吐收益，也不能据此承诺资源管理一定提升性能。
- 任务归属、任务准入和 agent 托管入口仍是设计建议，未包含在本包中。
